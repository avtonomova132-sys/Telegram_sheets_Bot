Подробное описание модулей — в `CLAUDE.md`. Деплой: ветка `uttaratantra-verse` → Railway.

## Правило для сообщений про Озон (обязательно для любой новой ветки)

Каждое новое напоминание/контрольная точка/алерт про Озон (акции, начисления, списания, подписки, габариты, остатки) выглядит так:

```
🛍️ Заголовок
Зачем: одна фраза — для чего это нужно (понятно без контекста)
Период: с ДД.ММ по ДД.ММ      ← если у напоминания есть период; считает бот, не Елена
Текст…
```

- Собирать через `ozonMsg.build({ title, why, period, body })` (`ozonMsg.js`); период отчёта — `ozonMsg.periodLine(today, accrualsReport.lastReportTo())`: со дня после конца прошлого присланного отчёта по сегодня, нет файла — с 1-го числа месяца.
- Готовый промпт для Claude — отдельным сообщением в блоке кода: `ozonMsg.sendCode(bot, chatId, prompt)` (поле `prompt` у контрольной точки). Длинное режется на части < 4096 (`ozonMsg.sendParts`).
- 🛍️ первой строкой ставится и автоматически: `ozonMsg.installMarker(bot)` оборачивает `bot.sendMessage` для личных чатов по ключевым словам (Ozon, Озон, акции, начисления, списания, подписка, габариты, остатки). «Зачем:» автоматически не добавляется — его пишет автор сообщения.
- Контрольная точка: поля `id`, `due`, `dueTime` («ЧЧ:ММ» по Бали, по умолчанию 10:00), `title`, `why`, `period`, `what`, `prompt` — в `SEED` в `controlPoints.js`.

Тесты: `node --test ozonMsg.test.js disputes.test.js returnsWatch.test.js fboPlacement.test.js`.
